# Mark model

`Mark.fbx` is a rigged 3D character with embedded Idle and Walk animation clips. It was generated with [Ara 3D Gen](https://github.com/olatunde85/3d-gen) from MakeHuman CC0 assets, then customized for the MGB prototype: a dark short-sleeve shirt, grey jeans, white sneakers, and wide brown wavy hair. `Mark.generator-params.json` records the body and outfit settings.

The hairstyle is adapted from `cortu_strawberry_cloud_hair` by Cortu Johnstone, distributed under CC0 in the [MakeHuman hair01 pack](https://www.makehumancommunity.org/assets/assetpacks/hair01.html). The underlying MakeHuman system assets are CC0. The model is a stylized approximation from reference photos, not an exact scan or likeness.

The Walk animation is based on CMU Graphics Lab motion capture data, retargeted by Ara 3D Gen. The motion data may be used in a game but may not be resold as a standalone motion capture collection.
