# Mark model

`Mark.fbx` is a rigged 3D character generated with [Ara 3D Gen](https://github.com/olatunde85/3d-gen) from MakeHuman assets, then customized for the MGB prototype: a dark short-sleeve shirt, grey jeans, white sneakers, and dark curly hair. `Textures/` contains the imported diffuse and normal maps; `Mark.generator-params.json` records the body and outfit settings. Unity does not detect the animation takes in this FBX, so the game currently uses a small procedural walk motion.

The hair is the `punkduck_alpha7_curly` MakeHuman asset. The model is a stylized approximation from reference photos, not an exact scan or likeness.

The Walk animation is based on CMU Graphics Lab motion capture data, retargeted by Ara 3D Gen. The motion data may be used in a game but may not be resold as a standalone motion capture collection.
